# TTR Frontend — лабораторная работа №2

Jinja2-шаблоны интерфейса для темы «История и культура», вариант 11 —
расчёт Type-Token Ratio.

- `templates/author_texts_feed.html` — лента опубликованных текстов;
- `templates/author_texts_add.html` — два состояния формы: «Далее» и «Опубликовать»;
- `templates/author_texts_grid.html` — корпус, фильтр длины и логическое удаление;
- `templates/_author_texts_bottom_nav.html` — нижняя навигация;
- `public/author_texts_styles.css` — общие стили;
- `public/media` — резервные фото и видео, отдаваемые SSR без MinIO;
- `minio-seed` — собственные фото и видео демонстрационных произведений.

На странице добавления пользователь вводит исходный текст в текстовое поле.
Длина, количество уникальных токенов и TTR считаются backend.
Фото и видео в ЛР-2 выбираются в интерфейсе, но ещё не отправляются на сервер.
До «Далее» доступны название и две кнопки выбора файлов, расположенные вертикально.
После «Далее» отображаются стандартные медиа и поля автора, года, описания, текста;
кнопка публикации меняет статус черновика. Год необязателен.
JavaScript отсутствует. Значение фильтра отображается после «Применить».

Интерфейс сохраняет оформление первой лабораторной: однотонный розовый фон,
белые карточки и серые скруглённые кнопки.

Запуск описан в README соседнего репозитория `lexical-diversity-backend`.
