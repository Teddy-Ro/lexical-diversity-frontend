# Lexical Diversity Frontend

Handlebars-шаблоны и CSS для лабораторной работы №1.

- Три мобильные страницы: лента, добавление черновика, плитка.
- Стиль повторяет RuLingva КФУ: светлый фон, тёмно-синий текст, бирюзовые акценты.
- Точные цвета: `#0B2F4F`, `#18A3A8`, `#F3F8FA`.
- Карточки: скругление `20px`, тень и бирюзовая рамка при `hover`.

Шаблоны запускаются через соседний репозиторий `lexical-diversity-backend`.
