# Author texts — SSR-интерфейс

Jinja2-шаблоны интерфейса для темы «История и культура», вариант 11 —
расчёт Type-Token Ratio.

- `templates/author_texts_feed.html` — лента опубликованных текстов;
- `templates/author_texts_add.html` — два состояния формы: «Далее» и «Опубликовать»;
- `templates/author_texts_grid.html` — корпус, фильтр длины и логическое удаление;
- `templates/_author_texts_bottom_nav.html` — нижняя навигация;
- `public/author_texts_styles.css` — общие стили;
- `public/media` — резервные фото и видео, отдаваемые SSR без MinIO;
- `minio-seed` — собственные фото и видео демонстрационных произведений.

Тематические поля — количество всех и уникальных токенов. Пользователь вводит
оба числа вручную; TTR рассчитывает бэкенд. Исходный текст, автор произведения
и год публикации в форме отсутствуют.

Корпус показывает опубликованные карточки и фильтрует их по минимальному
количеству токенов. Лента показывает одну карточку, видео, краткое описание,
два количества токенов и число лайков. Кнопка «Следующий» открывает следующую карточку.

Шаблон добавления содержит два состояния: название и выбор медиа до «Далее»;
описание и количества токенов перед публикацией. JavaScript отсутствует.
Значение фильтра отображается после отправки формы.

Интерфейс сохраняет оформление первой лабораторной: однотонный розовый фон,
белые карточки и серые скруглённые кнопки.

Шаблоны рендерит FastAPI с Jinja2; самостоятельного сервера у этого репозитория нет.
Запуск описан в [репозитории бэкенда](https://github.com/Teddy-Ro/lexical-diversity-backend).
В бэкенде ЛР-4 SSR используется для публичного просмотра корпуса и ленты,
а создание, публикация, удаление и лайки выполняются через REST API.
